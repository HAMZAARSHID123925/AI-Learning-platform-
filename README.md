# AI-Powered Adaptive Learning Platform
## Full-Stack Web Development Foundation

This project contains the Next.js frontend and FastAPI backend for the LMS platform.
The AI logic (Agents, RAG, LLM models) will plug into this foundation.

### Tech Stack
* **Frontend**: Next.js (React), TypeScript, Tailwind CSS
* **Backend**: FastAPI (Python)
* **Database**: PostgreSQL (with pgvector support for the AI team)
* **Specs**: See the `docs/` folder for the Spec-Driven Development contracts.
